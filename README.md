# -MU-MIMO-
卫星MU-MIMO能够利用空间与频率资源提高多用户传输能力和频谱效率，但OFDM多子载波叠加会产生较高的峰均功率比，使卫星功率放大器容易进入非线性区，造成EVM增大及BER恶化。同时，有限反馈开销、反馈噪声和传播时延会引起CSI反馈误差，影响用户间干扰抑制和PAPR控制效果。针对传统线性预编码缺乏时域峰值控制能力、非线性预编码计算复杂度较高的问题，及上述CSI反馈带来的问题，本课题拟研究低PAPR的CSI反馈与预编码联合学习方法，使用户侧CSI反馈网络与卫星端多用户预编码网络围绕最终通信性能进行端到端训练。综合评估PAPR、和速率、用户间干扰、BER、EVM、用户公平性及计算复杂度，验证所提方法在降低PAPR、减小功率放大器非线性失真和改善整体通信性能方面的有效性。
